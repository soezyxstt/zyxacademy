## Why this matters

Several packages are declared but never imported by any runtime code, adding install/CI weight, deploy image size, and misleading signals. `pg` directly contradicts the SQLite-only architecture AGENTS.md mandates. `shadcn` is a scaffolding CLI pinned as a runtime dependency, dragging a flagged express/hono/qs subtree into production. Two committed lockfiles (`bun.lock` + `package-lock.json`) resolve independently and drift. Removing these is low-risk cleanup, verified by "zero importers."
