# Student community di Expo

Ekspor `CommunityScreen` menerima kontrak `StudentScreenProps` dari shell Student. Entry ini mencakup 19 pola rute. `communityCases` menyediakan tiga skenario awal per pola dengan URL konkret. `createCommunityFixtureRequest` menyediakan state sintetis terisolasi untuk setiap transport. Nilai `unavailable` memutus permintaan pertama agar percobaan ulang dapat diperiksa.

Alias Student `/discussions` mengganti entri dengan `/dashboard/discussions` dan mempertahankan parameter berulang. Alias `/leaderboard/academic` mempertahankan parameter dan mengatur `tab=academic`. `/settings?tab=email` mengikuti alias pengaturan notifikasi web. Pemanggil mengelola tumpukan navigasi dan pemulihan posisi scroll.

## Operasi dan otorisasi

Prefix operasi baru adalah `/api/native/student/community/`. GET dan POST memeriksa origin, sesi Better Auth yang masih berlaku, kecocokan akun dari transport dan keanggotaan murid. Respons baru memakai `Cache-Control: private, no-store`. Operasi domain melakukan pemeriksaan yang lebih sempit sebelum merespons. Binding Resource memilih data yang diperlukan layar, termasuk nama dan nilai akademik yang memang ditampilkan web. ID akun, email rekan dan snapshot penilaian tidak ikut dalam hasil ranking.

## Integrasi dan bukti

- Shell menyuntikkan sesi dengan `sessionId`, transport HTTPS dan fungsi navigasi. Bridge `onLocaleChanged` memperbarui konteks akun. `devicePush` memasok status izin, registrasi dan permintaan izin. `nativeAuthScheme` serta `openExternal` diperlukan untuk handoff koneksi Google Calendar, Google Meet dan pengaturan browser. Pemilih gambar diskusi memakai bridge pemilih berkas Student jika tersedia.
- Composer diskusi memakai `SharedUiComposer` dengan teks sumber dan penyisipan mention pada posisi kursor. Pembaca memakai pembatas Markdown yang sama untuk heading, penekanan, kode, tautan aman, dan mention. Typesetting rumus, pembaruan live, pemulihan draf diskusi lintas pembukaan layar, unduhan lampiran asli dan pengakuan baca berdasarkan area terlihat masih membutuhkan komponen bersama. Pengakuan baca manual memakai receipt dan pesan pada halaman yang dibaca. Integrasi persetujuan Google Calendar dan registrasi push masih memerlukan pengujian perangkat.
- Studio peliharaan memakai poster katalog. Pratinjau animasi, pakaian terpasang secara visual dan Cat Practice membutuhkan renderer GLB native. Pengaturan tampilan native menyediakan tema dan haptik jika bridge tersedia. Preferensi web seperti density, dekorasi latar, ukuran huruf dan animasi belum dipetakan ke pengaturan native.
- Penjadwalan menerima tautan persiapan. Penampil dokumen, lampiran persiapan dari perangkat, perekaman sesi dan kalender mingguan dari `Calendar` bersama belum dibuktikan di perangkat. Rute `/calendar` mempertahankan tampilan agenda dan pemilah kategori dari web. Scope tindakan pengelolaan sesi tutor berada di alur tutor.
- Unit fixture `bun test packages/native-parity/student/community/community.test.ts` memeriksa alias, kontrak skenario, lingkup ranking, data publik dan deduplikasi fixture. Pemeriksaan HTTP opt-in memakai Next dan PostgreSQL lokal sintetis. Jalankan dengan `STUDENT_COMMUNITY_HTTP_BASE` yang menuju server loopback, database `student_evidence` dan sesi sintetis dari `tests/visual/native-parallel/student/product/`. Suite ini tidak diarahkan ke staging atau production.
- Endpoint baru tercatat sebagai UI-only di katalog admin MCP. Registri tool/scope, consent, discovery, playbook, paket skill, host prompt dan binding environment tetap mengikuti domain asli. Produk native belum memiliki bukti nol piksel berbeda di Android dan iOS. Fixture dan tangkapan web mengukur lapisan masing-masing.

### Verifikasi HTTP lokal

Pada 26 November 2026, suite komunitas lulus 4 dari 4 kasus dengan 41 assertion pada Next.js Turbopack dan PostgreSQL sintetis `student_evidence`. Server loopback memakai snapshot `7d93b3a5984814ee382ccd36d9ceff8cb34abbcd`. Pengujian membuktikan sesi dan kecocokan akun, penolakan aktor diskusi berperan ganda, filter enrollment yang diarsipkan atau dicabut, pemisahan skor akademik dan XP partisipasi, proyeksi profil dan blokir, tujuh tanggal WIB pada jadwal, respons arsip refleksi kosong, serta isolasi penyimpanan jadwal notifikasi antara dua akun. Data sintetis dibersihkan setelah suite.

```sh
STUDENT_COMMUNITY_HTTP_BASE=http://127.0.0.1:3140 \
  bun --env-file="$STUDENT_EVIDENCE_ENV" test \
  tests/visual/native-parallel/student/product/community-http.test.ts
```

`STUDENT_EVIDENCE_ENV` menunjuk ke berkas lokal server uji yang memuat database dan konfigurasi Better Auth fixture. Suite memeriksa nama database dan host loopback sebelum membuat rekaman. Jalankan setelah seed Student memberi sesi sintetis untuk kasus enrollment dicabut. Hasil ini membuktikan kontrak Next.js melalui HTTP lokal. Bukti Expo, Android dan iOS dicatat lewat jalur terpisah.

### Batas data pada ranking kursus

Uji HTTP tambahan menjalankan handler `course-ranking` hasil commit `1581156e` melalui `AppRouteRouteModule.handle` dari versi Next.js di repo, dengan PostgreSQL lokal dan sesi Better Auth bertanda tangan. Kelima peserta memiliki skor berbeda. Respons untuk peserta peringkat kelima hanya memuat tiga baris bernama serta `ownRank: 5` dan `totalStudents: 5`. Sesi anonim menghasilkan 401. Akun yang tidak berhak dan enrollment yang sudah berakhir mendapat 403. Skenario lulus dengan 10 assertion, termasuk metrik podium dan hasil simulasi kosong. Fixture sementara dibersihkan setelah pengujian.

Tes yang sama dapat dijalankan pada server produk lokal yang memuat commit tersebut dengan `STUDENT_COMMUNITY_HTTP_BASE` menunjuk ke origin server, lalu `bun --env-file=.env.local test -t "course ranking sends three named rows" tests/visual/native-parallel/student/product/community-http.test.ts`.
