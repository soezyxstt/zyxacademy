## Backend and MCP handoff

The shared components above should receive already-authorized data and callbacks. Hiding a control is never server authorization. UI composition, navigation selection, local search expansion and presentation do not themselves require a new backend operation or MCP tool. This source-only inventory changes no protocol, scope, consent, discovery, playbook, skill, host prompt, environment binding or server. Any later behavior change must repeat the mandatory MCP review in `AGENTS.md`, including `lib/admin-mcp/operations-catalog.ts`, `docs/operations/admin-mcp.md` and affected checks. Do not infer that a partial catalog entry covers every action or that repository changes publish or deploy MCP.

Before implementing an HTTP adapter, inspect the existing route/action, schema, environment and local Next.js guide, then record input, output, denial, validation, idempotency and retry per operation. Coordinate changes to auth, shared transport or cross-domain endpoints with integration. No backend operation, native integration, device test or MCP deployment has been verified by this inventory.
