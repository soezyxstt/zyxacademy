# Zyx Academy Showcase Asset Checklist

Store these assets in the future public showcase repository under `assets/`.

## Required

- `assets/hero.png` — clean student dashboard or course page
- `assets/material.png` — learning material view
- `assets/flashcards.png` — spaced-repetition review flow
- `assets/assessment.png` — question practice / assessment flow
- `assets/zyra.png` — Zyra answering a safe grounded question
- `assets/admin-authoring.png` — sanitized authoring or content-pipeline screen
- `assets/progress.png` — student progress or analytics view

## Strongly recommended

- `assets/architecture.svg` or `assets/architecture.png` — polished application architecture
- `assets/content-pipeline.svg` or `assets/content-pipeline.png` — source → knowledge → products → retrieval flow
- `assets/demo-student.mp4` or external video link — 30–60 second student flow
- `assets/demo-zyra.mp4` or external video link — short grounded-tutor demo

## Screenshot rules

- Use demo accounts and non-sensitive course content.
- Hide student names, emails, IDs, access tokens, unpublished questions, admin credentials, and private source files.
- Do not redistribute copyrighted PDFs or source material unless you have the right to publish them.
- Keep one consistent viewport and theme where possible.
- Prefer a sequence that explains a complete learning flow rather than disconnected screens.

## Best demo story

Choose one safe concept that you are allowed to show publicly and use it through the full flow:

1. Open the learning material.
2. Review one related flashcard.
3. Answer one practice question.
4. Ask Zyra a question about the same concept.
5. Show the related progress update.

This gives recruiters one clear end-to-end product story and shows that the learning surfaces share the same underlying content system.
