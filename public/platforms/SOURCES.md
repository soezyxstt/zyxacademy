# Platform artwork

Windows, Android, Debian, Linux and Apple use the original SVGs from [Devicon v2.16.0](https://github.com/devicons/devicon/tree/v2.16.0/icons). The local filenames map to `icons/<name>/<name>-original.svg`. The Windows icon uses the name `windows11`. See `LICENSE`.

The iPhone option uses the [iOS wordmark from Simple Icons 13.0.0](https://github.com/simple-icons/simple-icons/blob/13.0.0/icons/ios.svg). See `LICENSE-simple-icons.md`.
